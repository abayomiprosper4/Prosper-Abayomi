## 💻 Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites

You need a web browser and a code editor (like [VS Code](https://visualstudio.com)). If using a framework, ensure you have [Node.js](https://nodejs.org) installed.

### Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com
   ```

2. **Navigate into the directory:**

   ```bash
   cd your-repo-name
   ```

3. **Open the project:**
   ```bash
   npm install
   npm run dev
   ```

### Portfolio AI assistant

The chat assistant uses a Vercel serverless function and the OpenAI API for open-ended questions. Greetings and common profile questions have grounded responses that work without an API key.

For AI-generated replies, set `OPENAI_API_KEY` in a local `.env.local` file and in the Vercel project's server-side environment settings. Optionally set `OPENAI_MODEL` to select a compatible chat-completions model. Do not use a `VITE_` prefix or commit the key. The Vite development server serves `/api/chat` locally.
