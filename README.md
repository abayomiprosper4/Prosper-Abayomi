## 💻 Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites

You need a web browser and a code editor (like [VS Code](https://visualstudio.com)). If using a framework, ensure you have [Node.js](https://nodejs.org) installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the directory:**
   ```bash
   cd your-repo-name
   ```

3. **Open the project:**
     ```bash
     npm install
     npm run dev
     ```
